# codyssey

코디세이 부트캠프를 소개하고, 교육생으로 생활하며 얻은 실용적인 팁과 경험을 공유하는 레포지터리입니다.

## 레포지터리의 목적

이 레포지터리는 두 독자를 위해 운영합니다.

- **포트폴리오를 평가하는 분들께**: 코디세이 부트캠프의 교육 과정과 활동 배경을 소개하여, 제가 어떤 환경에서 학습하고 프로젝트를 수행했는지 이해하는 데 도움을 드리고자 합니다.
- **함께 배우는 교육생들께**: 부트캠프 생활에 필요한 정보와 직접 경험하며 얻은 팁을 공유하여, 교육 과정에 적응하고 학습을 이어가는 데 도움을 드리고자 합니다.

부트캠프 내부 용어나 제도는 처음 접하는 분도 이해할 수 있도록 설명하고, 교육 자료에 담긴 안내와 개인적인 경험·의견은 구분하여 정리합니다. 생활 팁은 경험이 쌓이는 대로 추가합니다.
